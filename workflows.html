🎬 5 workflow điển hình trong VS Code

1. Task mới — mở panel rồi gõ

# Mở project trong VS Code # Click icon ✨ Spark (góc trên-phải) → mở Claude panel > Thêm chức năng login với validate email + mật khẩu > 8 ký tự. Viết test luôn. # Claude tự đọc project → code → test → hiện diff trong tab # Bạn Accept hoặc chỉnh trong diff rồi Accept

2. Sửa code đang chọn — phím tắt Alt+K

# 1. Chọn 5-10 dòng code trong editor # 2. Nhấn Alt+K → tự chèn @file#5-15 vào prompt # 3. Gõ: > refactor đoạn này thành async/await # Claude sửa đúng vị trí → Accept

3. Hôm sau muốn tiếp tục task dở

# Mở lại VS Code → click ✨ Spark # Sessions cũ hiện trong panel → click chọn → tiếp # Hoặc qua terminal: $ claude --continue # session gần nhất $ claude --resume # picker chọn session cũ

4. Change LỚN — Plan mode trước

# Nhấn Shift+Tab → đổi sang Plan mode > Refactor authentication thành module riêng. # Claude CHỈ lên kế hoạch — KHÔNG sửa file # Review plan → Accept → giờ mới execute

5. Review code trước khi commit

# Trong Claude panel: > review thay đổi của tôi, tìm bug + style issues # Claude tự đọc git diff → list vấn đề > sửa các vấn đề bạn vừa liệt kê # Sạch xong: > commit changes với message rõ ràng

✍️ Công thức prompt

1. Cụ thể, không mơ hồ

prompt-comparison.md
❌ "thêm test"
❌ "fix bug"
❌ "làm code đẹp hơn"

✅ "Viết unit test cho hàm loginUser() trong @src/auth/user.ts."
   "  Test cases: email + password đúng → true,"
   "  password rỗng → false, email sai format → false."
   "  Chạy npm test sau khi viết xong."

2. Dùng @ để chỉ file/folder

❌ "thêm chức năng login" ✅ "Thêm chức năng login. Tạo file @src/pages/login.tsx. Dùng API POST /api/auth/login. Validate trong @src/utils/validate.ts." # Mẹo: gõ @ trong panel → autocomplete file/folder # Hoặc chọn code rồi Alt+K → tự chèn @file#lines

3. Yêu cầu verify (test/chạy)

❌ "viết hàm xong rồi" ✅ "Viết hàm xong, chạy npm test để verify pass. Nếu fail, fix cho đến khi pass."
💡 Công thức prompt tốt
WHAT (làm gì cụ thể) + WHERE (@file nào) + VERIFY (test/chạy gì). Đủ 3 → ít phải sửa lại.
