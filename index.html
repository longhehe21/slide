# Claude Code trong VS Code

$ câu lệnh + phím tắt dev nên biết
AI coding tool sống ngay trong VS Code.
Chat panel (✨ Spark) hoặc terminal tích hợp — cùng 1 tool.

Sau buổi này, bạn cài được extension, dùng Alt+K để Claude sửa code đang chọn, biết khi nào --continue, /clear vs /compact, và viết được prompt mà nó không "lạc trôi".
