Vì sao Claude Code khác Cursor / Copilot? #01

⊙ Open @longhehe21 opened this issue · vài phút trước
@longhehe21 commented · vài phút trước

3 cách dev hay dùng AI hỗ trợ code hiện nay:

💬 Chat website (ChatGPT, Claude.ai)

  • Cách dùng: copy code vào browser, hỏi, copy code trả lời, dán lại IDE
  • Hạn chế: không hiểu cấu trúc project, không tự sửa file, không chạy được lệnh

🤖 Copilot / Cursor

  • Cách dùng: plugin trong IDE, gợi ý code khi gõ, có chat trong sidebar
  • Hạn chế: bị bó trong IDE, không tự chạy lệnh terminal, không tự test code

⚡ Claude Code

  • Cách dùng: chạy trong terminal, gõ yêu cầu bằng tiếng người
  • Tự làm: đọc file, sửa file, chạy lệnh, chạy test, fix bug — toàn bộ task
  • Có agent: phân chia task lớn thành nhiều bước, làm tuần tự
💡 Tóm 1 câu
Chat website = hỏi đáp · Copilot/Cursor = gợi ý code trong IDE · Claude Code = "junior tự làm việc" trong terminal.

🎬 Ví dụ thực tế

Bạn gõ trong terminal:

$ claude # Trong session, gõ tự nhiên: > Thêm chức năng login cho project này. Validate email + password tối thiểu 8 ký tự. Viết test luôn. # Claude Code sẽ: # 1. Đọc cấu trúc project # 2. Tạo file login.tsx, validate.ts # 3. Viết unit test # 4. Chạy test, fix nếu fail # 5. Báo "done" + tóm tắt thay đổi

→ Bạn không phải copy-paste, không phải tự test. Claude tự làm.
