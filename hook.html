Tại sao cần Git workflow nâng cao? #01

⊙ Open @longhehe21 opened this issue 2 hours ago · 3 comments
@longhehe21 commented · 2 hours ago

Cùng 1 chức năng, lịch sử git có 2 kiểu. Bên rối — người review không hiểu bạn làm gì. Bên sạch — đọc 30 giây là biết.

🌀 Kiểu rối — 8 commit lẫn lộn

$ git log a8f3b2c sửa typo 2e7d910 sửa tiếp 9c1ab47 đang làm login 5b2f8e3 sửa nữa 4d6c1a8 fix bug 7e8b3f2 xong rồi 3a9d7e1 xong thật 1c4f9b7 đăng nhập ok
🚫 Hậu quả
Người review không biết commit nào quan trọng. Có bug — không biết commit nào gây ra.

✨ Kiểu sạch — 3 commit có ý nghĩa

$ git log a8f3b2c Thêm trang đăng nhập kèm phần kiểm tra dữ liệu 9c1ab47 Sửa lỗi sai mật khẩu nhảy về trang trắng 5b2f8e3 Viết test cho form đăng nhập
💡 Lợi ích
Mỗi commit 1 ý. Đọc tên là hiểu code làm gì. Có bug — biết commit nào, gỡ ra 1 phát.
