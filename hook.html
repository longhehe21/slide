Vì sao Claude Code khác Cursor / Copilot? #01

⊙ Open @longhehe21 opened this issue · vài phút trước
@longhehe21 commented · vài phút trước

3 cách dev hay dùng AI hỗ trợ code trong VS Code:

💬 Chat website (ChatGPT, Claude.ai)

  • Cách dùng: copy code từ VS Code, dán vào browser, hỏi, copy code trả lời, dán lại VS Code
  • Hạn chế: đổi tab liên tục, không hiểu cấu trúc project, không tự sửa file, không chạy được lệnh

🤖 Copilot / Cursor

  • Cách dùng: extension trong IDE, gợi ý code khi gõ, có chat trong sidebar
  • Hạn chế: chỉ gợi ý, không chủ động đọc cả project, không chạy test, không sửa nhiều file cùng lúc

⚡ Claude Code (trong VS Code)

  • Cài 1 extension → có chat panel ngay trong VS Code (icon ✨ Spark góc trên-phải)
  • Tự làm: đọc file, sửa file, chạy lệnh terminal, chạy test, fix bug — toàn bộ task
  • Diff hiện ngay trong tab editor → bạn xem rồi Accept / Reject từng thay đổi
  • Có agent: chia task lớn thành nhiều bước, làm tuần tự
💡 Tóm 1 câu
Chat website = hỏi đáp (copy-paste) · Copilot/Cursor = gợi ý code khi gõ · Claude Code = "junior tự ngồi sửa code" ngay trong VS Code, mình review diff rồi Accept.

🎬 Ví dụ thực tế trong VS Code

# Mở project trong VS Code # Click icon ✨ Spark → mở Claude panel bên phải > Thêm chức năng login cho project này. Validate email + password tối thiểu 8 ký tự. Viết test luôn. # Claude sẽ: # 1. Đọc cấu trúc project (tự, không cần chỉ) # 2. Tạo file login.tsx, validate.ts # → diff hiện trong tab editor # 3. Viết unit test → hiện thêm tab # 4. Chạy test (trong VS Code terminal), fix nếu fail # 5. Bạn xem từng diff → Accept / Reject

→ Không phải copy-paste, không đổi tab. Mọi thứ trong 1 cửa sổ VS Code.
