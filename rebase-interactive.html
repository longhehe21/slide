Rebase tương tác: gộp 5 commit "WIP" thành 1 commit sạch #03

⊙ Open @longhehe21 opened this issue 1 hour ago
@longhehe21 commented · 1 hour ago

git rebase -i HEAD~N mở editor cho phép sửa N commit gần nhất. Lệnh hay nhất để dọn dẹp trước khi mở PR.

Workflow điển hình

$ git rebase -i HEAD~5 # mở editor sửa 5 commit gần nhất # Editor hiện ra: pick a8f3b2 WIP login form pick 2e7d91 fix typo pick 9c1ab4 add validate pick 5b2f8e fix again pick 4d6c1a final final # Đổi 4 dòng dưới: `pick` → `squash` (viết tắt: s) pick a8f3b2 WIP login form squash 2e7d91 fix typo squash 9c1ab4 add validate squash 5b2f8e fix again squash 4d6c1a final final # Save & exit → editor mở lại cho bạn viết message mới gộp lại # → kết quả: 1 commit duy nhất với message sạch: feat(auth): trang login với validate

4 lệnh cần nhớ

pick (p) Giữ commit y nguyên (default).
squash (s) Hay dùng nhất. Gộp commit này vào commit ngay phía trên — code giữ, message gộp lại.
reword (r) Code giữ nguyên, chỉ đổi commit message. Hữu ích sửa typo.
drop (d) Xóa hẳn commit. Cẩn thận — không undo được sau khi push.
💡 Best practice
Luôn git rebase -i TRƯỚC khi mở PR. 8 commit "WIP" → 1-3 commit có ý nghĩa = reviewer biết ơn.
