Rebase tương tác: gộp 5 commit "WIP" thành 1 commit sạch #03

⊙ Open @longhehe21 opened this issue 1 hour ago
@longhehe21 commented · 1 hour ago

Lệnh quan trọng nhất: git rebase -i HEAD~5 = mở trình sửa cho 5 commit gần nhất, cho phép gộp / sửa tên / xóa chúng.

Ví dụ — gộp 5 commit lẫn lộn thành 1

$ git rebase -i HEAD~5 # mở trình sửa 5 commit gần nhất # Trình sửa hiện ra như này: pick a8f3b2 đang làm form login pick 2e7d91 sửa typo pick 9c1ab4 thêm kiểm tra pick 5b2f8e sửa lại pick 4d6c1a xong rồi # Đổi 4 dòng dưới từ `pick` → `squash` (gộp): pick a8f3b2 đang làm form login squash 2e7d91 sửa typo squash 9c1ab4 thêm kiểm tra squash 5b2f8e sửa lại squash 4d6c1a xong rồi # Lưu lại → trình sửa hỏi tên cho commit gộp. Viết tên mới: Thêm trang đăng nhập kèm phần kiểm tra # ↓ Kết quả: chỉ còn 1 commit duy nhất, tên rõ ràng

3 lệnh cần nhớ

pick Giữ commit y nguyên (mặc định)
squash Quan trọng nhất. Gộp commit này vào commit ngay phía trên — code giữ nguyên, chỉ tên bị gộp.
reword Chỉ đổi tên commit, code không động vào.
💡 Khi nào dùng
Luôn dọn dẹp trước khi đưa code cho người khác review. 8 commit lẫn lộn → 1-3 commit có ý nghĩa.
