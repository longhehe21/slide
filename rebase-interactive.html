03 · Rebase tương tác
Gộp 5 commit "WIP" thành 1 commit sạch
git rebase -i HEAD~5 # mở editor sửa 5 commit gần nhất # Editor hiện ra như này: pick a8f3b2 WIP login form pick 2e7d91 fix typo pick 9c1ab4 add validate pick 5b2f8e fix again pick 4d6c1a final final # Đổi 4 dòng dưới từ `pick` → `squash` (s): pick a8f3b2 WIP login form squash 2e7d91 fix typo squash 9c1ab4 add validate squash 5b2f8e fix again squash 4d6c1a final final # → Save & exit → editor mở lại cho bạn viết message mới gộp: feat(auth): trang login với validate
pick giữ commit
Không thay đổi gì. Mặc định.
squash gộp vào commit trên
Hay dùng nhất. Gộp commit này vào commit ngay phía trên → giữ thay đổi code, message gộp lại.
reword chỉ sửa message
Code giữ nguyên, chỉ đổi commit message. Sửa typo trong message.
drop xóa hẳn commit
Code của commit đó bị xóa luôn. Cẩn thận — không undo được sau khi push.
💡
Mẹo: luôn git rebase -i TRƯỚC khi mở PR. Squash 8 commit "WIP" thành 1-3 commit có ý nghĩa → review sướng hơn nhiều.
