Gõ trong session Claude Code (sau khi đã chạy claude). Gõ / để xem list, hoặc gõ thẳng tên lệnh.

🔧 Quản lý session

/help Xem tất cả commands có sẵn + cách dùng.
/clear Xóa sạch context. Dùng khi conversation rối, muốn task mới với đầu sạch.
/compact Nén conversation dài thành tóm tắt, giữ decisions + code quan trọng. Tiết kiệm token.
/resume Mở picker chọn session cũ (giống --resume nhưng dùng trong session).

🤖 Model + Plan

/model Đổi model GIỮA CHỪNG (vd /model opus khi gặp task khó).
/plan Vào plan mode. Claude lên kế hoạch, không sửa code. Review xong → execute.

⚙️ Project setup

/init Tạo file CLAUDE.md starter cho project (Claude tự explore + viết). Commit vào git để share team.
/permissions Cấu hình quyền — cho phép tự chạy npm, git mà không hỏi mỗi lần.
/mcp Quản lý MCP servers (kết nối Notion, Figma, Slack, GitHub...).

📊 Theo dõi

/cost Xem số token đã dùng + chi phí ước tính của session hiện tại.
💡 3 lệnh DÙNG NHIỀU NHẤT
/clear (khi rối) · /compact (khi context dài) · /plan (trước change lớn). Nhớ 3 cái này.
