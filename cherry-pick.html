Cherry-pick: lấy 1 commit lẻ từ branch khác #04

⊙ Open @longhehe21 opened this issue 1 hour ago
@longhehe21 commented · 1 hour ago

Tình huống: Bạn đang làm dở 1 chức năng. Đột nhiên phát hiện 1 lỗi nhỏ trong chính nhánh đó cần fix gấp đẩy lên main, mà chưa muốn merge cả chức năng.

Cách làm — 2 bước

# 1. Tìm mã của commit cần lấy $ git log a8f3b2c Sửa lỗi bảo mật trang đăng nhập ← cái này cần lấy gấp 9c1ab47 Thêm trang đăng nhập 5b2f8e3 đang làm dở # 2. Sang main và "hái" đúng 1 commit đó $ git checkout main $ git cherry-pick a8f3b2c # ↓ Xong. Commit sửa lỗi đã có trên main. Chức năng đang làm dở vẫn ở nhánh riêng.

Trước & Sau

Trước khi hái: main ●──●──● \ nhánh ●──●──★ ← commit sửa lỗi đang kẹt Sau cherry-pick: main ●──●──●──★ ← đã có trên main \ nhánh ●──●──★ ← bản gốc vẫn còn
📝 Ghi nhớ
Cherry-pick = "hái 1 commit lẻ từ nhánh khác". Chỉ lấy đúng cái bạn cần, không kéo theo cả nhánh.
