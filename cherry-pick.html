Cherry-pick: lấy 1 commit lẻ từ branch khác #04

⊙ Open @longhehe21 opened this issue 1 hour ago
@longhehe21 commented · 1 hour ago

Use case: hotfix nằm trong feature branch chưa xong, cần đẩy lên main gấp mà không kéo theo cả branch.

Lệnh 3 bước

# 1. Tìm hash commit cần lấy $ git log feat/login --oneline a8f3b2c fix: vá lỗ hổng XSS login 9c1ab47 feat: thêm trang login 5b2f8e3 WIP # 2. Sang main và cherry-pick commit fix $ git checkout main $ git cherry-pick a8f3b2c # Xong. Commit fix XSS đã có trên main, # KHÔNG kéo theo feat/login chưa xong.

Trước / Sau

Trước cherry-pick: main ●──●──● \ feat ●──●──★ ← XSS fix kẹt ở đây Sau git cherry-pick a8f3b2c: main ●──●──●──★' ← commit mới, hash khác \ feat ●──●──★ ← bản gốc vẫn còn
📝 Lưu ý hash
Commit ★' trên main có cùng nội dung nhưng hash khác với commit gốc ★ (vì khác parent).
⚠ Mẹo
Multi-cherry-pick: lấy 1 dãy commit liên tiếp:
git cherry-pick A^..B (từ A đến B, kể cả 2 đầu).
Có conflict? → git cherry-pick --continue hoặc --abort.
