04 · Cherry-pick
Lấy 1 commit lẻ từ branch khác

🍒 LỆNH đơn giản

# 1. Tìm hash commit cần lấy git log feat/login --oneline a8f3b2c fix: vá lỗ hổng XSS login 9c1ab47 feat: thêm trang login 5b2f8e3 WIP # 2. Sang main và cherry-pick commit fix git checkout main git cherry-pick a8f3b2c # Xong! Commit fix XSS đã có trên main, # mà KHÔNG kéo theo feat/login chưa xong.
Use case: hotfix nằm trong feature branch nhưng cần đẩy lên production GẤP, không thể chờ feature xong.

📊 Trước / Sau

Trước: main ●──●──● \ feat ●──●──★ ← XSS fix kẹt ở đây Sau git cherry-pick: main ●──●──●──★' ← commit mới \ feat ●──●──★ ← bản gốc còn đó
Commit ★' trên main có cùng nội dung nhưng hash khác với commit gốc ★.
📌
Multi-cherry-pick: lấy 1 dãy commit liên tiếp git cherry-pick A^..B (từ A đến B, kể cả 2 đầu).
Có conflict? → git cherry-pick --continue hoặc --abort.
