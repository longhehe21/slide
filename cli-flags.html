Mở terminal trong VS Code (Ctrl+`) → gõ các flag này trước khi vào session. Đây là 7 flag dev hay dùng nhất:

1. claude

$ claude # Mở session tương tác bình thường # → gõ yêu cầu → Claude làm → hoàn tất → giữ session mở

2. claude --continue · -c

$ claude --continue # Tiếp tục session GẦN NHẤT ở thư mục hiện tại # → giữ nguyên context, không bị mất

3. claude --resume · -r

$ claude --resume # Mở picker liệt kê các session cũ # → chọn 1 cái để quay lại (kể cả session tuần trước)

4. claude -p "prompt" · print mode

$ claude -p "tóm tắt commit gần đây" # Chạy 1 lần, in kết quả, thoát ngay (không tương tác) # → dùng cho script, pipe, CI/CD # Ví dụ pipe: $ git diff | claude -p "review thay đổi này"

5. claude --model <tên>

$ claude --model opus # task khó, code nhiều $ claude --model sonnet # cân bằng (mặc định) $ claude --model haiku # nhanh, đơn giản

6. claude --permission-mode plan

$ claude --permission-mode plan # Plan mode: Claude chỉ ĐỌC + lên kế hoạch, KHÔNG sửa file # → review plan trước khi cho phép execute # → an toàn cho change lớn

7. claude --worktree <branch>

$ claude --worktree feat/login # Tạo session riêng trên 1 branch khác # → làm feature A + fix bug B SONG SONG không xung đột
💡 4 flag DÙNG NHIỀU NHẤT
claude (mở) · --continue (tiếp tục) · --resume (chọn session cũ) · -p (chạy 1 lần). Nhớ 4 cái này là đủ 80% công việc.
