📛 GIT NÓI GÌ marker

# Khi conflict, file sẽ có 3 marker: function login(email, password) { <<<<<<< HEAD ← code của BẠN return api.post('/v1/login', { email, password }); ======= ← ranh giới return api.post('/auth/login', { username: email, pwd: password }); >>>>>>> main ← code của branch khác }
3 marker: <<<< HEAD = bạn · ==== = ranh giới · >>>> main = đối thủ. Xóa cả 3 marker sau khi chọn xong code.

🛠️ XỬ LÝ 3 bước

# 1. Xem file nào conflict git status # both modified: src/auth.js # 2. Mở file, sửa thủ công, xóa 3 marker # (dùng VSCode để click 'Accept Current' # hoặc 'Accept Incoming' tiện hơn) # 3. Stage + tiếp tục git add src/auth.js git rebase --continue # (hoặc git merge --continue) # Lỡ rối quá → quay lui: git rebase --abort
VSCode có UI 4 nút sẵn: Accept Current / Incoming / Both / Compare → nhanh hơn sửa tay.
💡
Tip giảm conflict: pull/rebase main thường xuyên (mỗi sáng) → conflict nhỏ thay vì chờ 1 tuần rồi conflict 50 file. 1 PR = 1 ý → ít file đụng = ít conflict.
