Xử lý conflict — đừng hoảng #05

⊙ Open @longhehe21 opened this issue 30 minutes ago
@longhehe21 commented · 30 minutes ago

Khi 2 người sửa cùng 1 dòng code, git không tự biết chọn ai → conflict. Git để lại "dấu phân cách" trong file cho bạn tự chọn.

📛 Trong file có 3 dấu phân cách

src/auth.js
function login(email, password) {
  <<<<<<< HEAD          // ← code CỦA BẠN
  return api.post('/v1/login', {
      email, password
  });
  =======                // ← ranh giới chia 2 bên
  return api.post('/auth/login', {
      username: email, pwd: password
  });
  >>>>>>> main           // ← code của NGƯỜI KHÁC
}
📝 Đọc 3 dấu
<<< đến === = code của bạn.
=== đến >>> = code của người khác.
Chọn giữ bên nào, hoặc gộp cả hai → xóa hết 3 dấu đi → save.

🛠 Xử lý — 3 bước

# 1. Xem file nào bị conflict $ git status # 2. Mở file → chọn code giữ → xóa 3 dấu <<< === >>> → save # 3. Báo git là xong, tiếp tục $ git add <tên-file> $ git rebase --continue # Nếu rối quá, muốn quay về như chưa bắt đầu: $ git rebase --abort
💡 Cách giảm conflict
Cập nhật main về nhánh của mình thường xuyên (mỗi sáng) → conflict nhỏ thay vì chờ 1 tuần conflict 50 file.
