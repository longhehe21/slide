Xử lý conflict — đừng hoảng #05

⊙ Open @longhehe21 opened this issue 30 minutes ago
@longhehe21 commented · 30 minutes ago

Khi 2 branch sửa cùng 1 dòng, git không tự gộp được → conflict. Git để lại marker trong file cho bạn tự chọn.

📛 Marker — git nói gì

src/auth.js · both modified
function login(email, password) {
  <<<<<<< HEAD          // ← code của BẠN
  return api.post('/v1/login', {
      email, password
  });
  =======                // ← ranh giới
  return api.post('/auth/login', {
      username: email, pwd: password
  });
  >>>>>>> main           // ← code của branch khác
}
📝 3 marker
<<< HEAD = code bạn · ==== = ranh giới · >>> main = code đối phương. Xóa cả 3 marker sau khi chọn xong code.

🛠 Xử lý — 3 bước

# 1. Xem file nào conflict $ git status both modified: src/auth.js # 2. Mở file, sửa thủ công, xóa 3 marker # (VSCode có UI 4 nút: Accept Current / Incoming / Both / Compare) # 3. Stage + tiếp tục $ git add src/auth.js $ git rebase --continue # (hoặc git merge --continue) # Lỡ rối quá → quay lui: $ git rebase --abort
💡 Tip giảm conflict
Pull/rebase main thường xuyên (mỗi sáng) → conflict nhỏ thay vì chờ 1 tuần rồi conflict 50 file.
1 PR = 1 ý → ít file đụng = ít conflict.
