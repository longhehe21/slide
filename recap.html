Cheat sheet — copy về để đầu giường:

🔧 4 câu lệnh CLI cốt lõi

cli-flags.sh
claude              # mở session bình thường
claude --continue   # tiếp tục session gần nhất
claude --resume     # chọn từ list session cũ
claude -p "..."     # chạy 1 lần, in kết quả, thoát

⚡ 3 slash commands cốt lõi

slash-commands.md
/clear     # context rối → xóa, bắt đầu sạch
/compact   # context dài → nén, giữ điểm quan trọng
/plan      # change lớn → plan trước, code sau

✍️ Công thức prompt

💡 Nhớ 3 chữ
WHAT (làm gì cụ thể) + WHERE (file nào) + VERIFY (test/chạy gì để kiểm tra).

🎯 4 ý chính cần nhớ

takeaways.md
1. Claude Code chạy trong TERMINAL, không phải IDE plugin.
   Không copy-paste, không chuyển tab — Claude tự sửa file.

2. 4 cách mở session: claude / --continue / --resume / -p
   Lưu context giữa các phiên — không phải kể lại từ đầu.

3. Khi context rối → /clear · Khi dài → /compact
   Trước change lớn → /plan (review trước khi sửa code).

4. Prompt cụ thể (WHAT + WHERE + VERIFY) = ít phải sửa lại.
