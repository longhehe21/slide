4 ý cần nhớ sau buổi học hôm nay:

tóm-tắt.md
1. Rebase = lịch sử sạch thẳng băng
   Merge  = giữ commit "gộp" thừa
   → Nhánh riêng → rebase. Nhánh chung → merge.

2. git rebase -i HEAD~5
   → Gộp / sửa tên commit TRƯỚC khi đưa code review.

3. git cherry-pick <mã commit>
   → "Hái" 1 commit lẻ từ nhánh khác sang nhánh hiện tại.

4. Conflict: 3 dấu <<< === >>>
   → Xóa 3 dấu → git add → git rebase --continue.
   → Rối quá → git rebase --abort để quay lui.
