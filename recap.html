06 · Tóm tắt
Nhớ 4 ý chính.
1
Rebase = lịch sử sạch tuyến tính · Merge = giữ commit merge thừa. Branch riêng → rebase, share team → merge.
2
Rebase tương tác git rebase -i HEAD~5 → squash/reword trước khi mở PR. Reviewer biết ơn.
3
Cherry-pick git cherry-pick <hash> → lấy 1 commit lẻ từ branch khác. Hotfix gấp lên main không cần merge cả branch.
4
Conflict: xóa 3 marker (<<< · === · >>>) → git add → --continue. Rối quá → --abort.
Cảm ơn — câu hỏi?
Golden rule: KHÔNG rebase code đã push lên public.
