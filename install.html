[Setup] Cài Claude Code trong VS Code #00

📌 Pinned @longhehe21 · 2 cách · 1 phút
@longhehe21 · hướng dẫn cài

⚡ Cách 1 — Extension (khuyên dùng)

vscode-extension.md
1. Mở VS Code → nhấn Ctrl+Shift+X (Extensions)
2. Gõ tìm: "Claude Code"  → bấm Install
3. Reload VS Code (nếu được hỏi)
4. Click icon ✨ Spark ở góc trên-phải → mở panel
5. Sign in qua browser → xong

→ UI đẹp, có chat panel, diff hiện ngay trong tab editor.

🖥️ Cách 2 — CLI + Terminal trong VS Code

Mở terminal trong VS Code bằng Ctrl+` rồi chạy:

# Windows (PowerShell) $ irm https://claude.ai/install.ps1 | iex # macOS / Linux $ curl -fsSL https://claude.ai/install.sh | bash # vào project rồi mở session $ cd ~/my-project $ claude # → copy link → mở browser → login → xong

🔗 Kết nối CLI với VS Code editor

Khi đang chạy claude trong VS Code terminal, gõ:

> /ide # Claude detect VS Code đang mở → kết nối # Từ giờ: diff hiện trong tab editor, biết file đang chọn, # biết selection của bạn, mở file bằng click

✅ Kiểm tra

$ claude --version # Hiện ra phiên bản → OK
💡 Mẹo chọn cách nào
Mới bắt đầu → Extension (Cách 1) cho dễ. Đã quen terminal → CLI + /ide (Cách 2) cho có đủ slash commands. Hôm nay tôi demo cả 2.
