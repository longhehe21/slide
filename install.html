[Setup] Cài Git nhanh — 3 hệ điều hành #00

📌 Pinned @longhehe21 · setup guide cho người mới
@longhehe21 · hướng dẫn cài

Chạy 1 dòng lệnh tương ứng hệ điều hành. Sau khi cài, làm tiếp cấu hình lần đầu ở dưới.

🪟 Windows

# Cách 1: dùng winget (có sẵn trên Windows 10/11) $ winget install --id Git.Git -e --source winget # Cách 2: tải file .exe về cài bằng tay # https://git-scm.com/download/win

🍎 macOS

# Cách 1: dùng Homebrew (khuyên dùng) $ brew install git # Cách 2: cài Xcode Command Line Tools (có git sẵn) $ xcode-select --install

🐧 Linux

# Ubuntu / Debian $ sudo apt update && sudo apt install git -y # Fedora / RHEL $ sudo dnf install git -y # Arch $ sudo pacman -S git

✅ Kiểm tra cài thành công

$ git --version # Thấy số phiên bản kiểu: git version 2.45.0

⚙️ Cấu hình lần đầu (BẮT BUỘC)

Sau khi cài, gõ 4 lệnh sau (chỉ 1 lần, dùng mãi):

# 1. Đặt tên hiển thị trong commit $ git config --global user.name "Tên của bạn" # 2. Đặt email (dùng email GitHub nếu có) $ git config --global user.email "email@example.com" # 3. Đổi editor mặc định sang VSCode (đỡ phải dùng vim) $ git config --global core.editor "code --wait" # 4. Đặt tên nhánh mặc định là main (thay vì master) $ git config --global init.defaultBranch main
💡 Test nhanh sau khi cài
Tạo 1 thư mục thử rồi: git init → git add . → git commit -m "first". Chạy được = OK.
