[Setup] Cài + đăng nhập Claude Code #00

📌 Pinned @longhehe21 · 1 dòng lệnh, 30 giây
@longhehe21 · hướng dẫn cài

🪟 Windows (PowerShell)

$ irm https://claude.ai/install.ps1 | iex

🍎 macOS / 🐧 Linux

$ curl -fsSL https://claude.ai/install.sh | bash

🔑 Đăng nhập (lần đầu)

# vào thư mục dự án $ cd ~/my-project # khởi động claude → nó tự mở link login $ claude # → copy link → mở browser → đăng nhập # → terminal tự cập nhật, sẵn sàng dùng

✅ Kiểm tra

$ claude --version # Hiện ra phiên bản → OK
💡 Mẹo cài
Không cần npm, không cần Node.js cài sẵn. Script trên tự tải binary phù hợp với máy.
